Ganti Password Admin

Password disimpan dalam bentuk hash SHA-256. Setelah mengganti password, pastikan mengunduh ulang config.js jika ingin menerapkannya ke situs yang dipublikasikan.

Simpan Profil Permanen untuk Publish (Vercel)

Perubahan yang Anda simpan di Panel Admin tersimpan di localStorage browser lokal ini. Agar profil yang sudah diedit tetap permanen dan tidak berubah kembali ke default saat di-upload ke Vercel atau dibuka dari perangkat lain, lakukan salah satu langkah berikut:

Cara 1 (Jika edit melalui Panel Admin ini): Klik tombol Unduh File config.js Terbaru di bawah, lalu timpa file js/config.js di folder proyek Anda sebelum melakukan upload/deploy ke Vercel.

Cara 2 (Jika edit teks langsung di file HTML): Perubahan yang Anda tulis langsung di index.html, profil.html, atau kontak.html otomatis dipertahankan saat dipublikasikan selama belum ditimpa oleh ekspor Admin.
